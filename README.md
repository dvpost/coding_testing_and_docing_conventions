# Coding, Testing & Documentation Conventions

Общая конвенция разработки, тестирования и документации для проектов,
в которых код создают и изменяют AI-агенты под руководством человека.
Правила не привязаны к языку или фреймворку и применимы к новым и существующим проектам.

Документ предназначен для AI-агентов, разработчиков и владельцев проектов.
Он задаёт общий порядок работы: изучение области изменения, организацию кода,
проверку поведения тестами и поддержку документации о текущем состоянии системы.

Полные правила — в [основном документе конвенции](coding_testing_and_docing_conventions.md).
